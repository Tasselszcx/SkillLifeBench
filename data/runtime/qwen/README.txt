This package contains 534 completed Qwen checkpoint/policy episodes: each checkpoint has 89 Default clean episodes, 89 Default challenged episodes, and 89 Check challenged episodes.

final/case-verdicts.jsonl is the Boolean final verdict ledger with exact source and outcome hashes, local checkpoint identity, native invocation binding proof, and explicit Codex-assisted adjudication where used. The adjudications are not human annotations. Original automatic measurements and actual model responses remain in the qualified and raw archives; private host-location metadata uses stable /slb aliases.

final/leaderboard-default-verdicts.jsonl contains the same 356 Default records used in final/paired-default-check.json. No alternative baseline run or author aggregate is substituted. Pilot episodes are excluded.

The raw-local9b/raw-local4b/raw-protocol .tar.xz archives contain publication copies of every original full-run attempt, including failed attempts, exact prompts/API requests/API responses, policy bindings, outcomes, and native receipts with before/after JSON snapshots and opaque native state. The local endpoints do not use gateway credentials. The protocol is source/execution-plan/manifest.json. Frozen source identities remain in source_sha256 fields and original record references; the published files and archives have separate verified SHA-256 hashes. Archive filenames retain their source identifiers. If public_parts are listed, concatenate them in order and verify the full archive SHA-256 before extraction; each part is at most 90 MiB.

raw-file-manifest.jsonl and qualified-file-manifest.jsonl map recorded paths to archive members and public SHA-256 hashes. Transformed members also carry source_sha256/source_bytes, preserving the identities referenced by receipt chains. publication-bindings.json records file-level derivatives. Extract to a fresh directory, resolve recorded paths through these manifests, and verify bytes before replaying scoring. JSON state snapshots support offline scoring; opaque native state is hashed rather than decoded by the verifier. The included code/ dependencies and source/contracts/ support standalone CPU scoring reproduction. Full native task re-execution would additionally require the original benchmark implementation and model weights; the portable verifier executes neither.

Reproduce on CPU: python3 verify_release.py --evidence-root /tmp/skilllife-qwen-evidence --extract --output /tmp/qwen-verification.json
The verifier checks every byte binding, reconstructs receipt-bound task inputs, authenticates public bytes while checking their explicit original-source identities, reruns the exact frozen task/goal scoring, applies explicit trace-bound Codex decisions, and verifies all 178 Default/Check pairs reuse the 356 leaderboard Default records.

The scoring implementation is task v56.5 and goal v56, followed by the bound explicit semantic decision ledger. Default/Check differ only by the exact appended authorization-check instruction block; task, tool schema, initial scenario state, checkpoint, harness, decoding and budgets remain fixed for each paired checkpoint study.
