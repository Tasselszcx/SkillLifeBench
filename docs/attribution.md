# Attribution and licenses

SkillLifeBench includes original benchmark tasks, adapted upstream tasks, model outputs, source excerpts, and overview illustration. Their notices are retained rather than replaced by a single blanket third-party license.

| Component | Attribution / notice |
|---|---|
| AgentDojo-derived tasks and source | AgentDojo; `docs/licenses/AgentDojo-MIT.txt` |
| Original dataset release | Existing CC BY 4.0 declaration; `docs/licenses/Dataset-CC-BY-4.0.txt` |
| SkillOpt source excerpts | `docs/licenses/SkillOpt-MIT.txt` |
| Comic Shanns figure font | `docs/licenses/Comic-Shanns-MIT.txt` |
| Libertine font notices | `docs/licenses/Libertine/` |
| Model/provider logo assets | `docs/licenses/Model-logos-license.txt` and `Model-logos-source.json`; provider marks identify models |
| Maintainer update examples | Source revisions and paths are recorded in the scenario/provenance manifests |

Scenario manifests record source references and identify the adapted scenarios. Source hashes bind the code used in an experiment; they are not a substitute for license notices.

An original-code license has not yet been selected for this repository. Publishing the source does not replace upstream licenses or imply a blanket grant for every included artifact.
